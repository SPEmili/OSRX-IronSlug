# What is IronSlug?
OS/RX IronSlug is a very simple RTF text editor written in Java designed to be an evolution of the defunct TXT editor Mindcell Office. It has a very very simple user interface as to not get in your way, opposing what seems to be the trend with modern text editing software.
The entomology of IronSlug derives from a typewriter's type slug (the part that presses letters into paper) and the iron-like robustness of IronSlug compared to Mindcell Office.

# What's still to be added?
As of version 0.4.2 (September 22 2026) highlighting, hyperlinks, images/drawing and integration with other OS/RX software is still in the works. Despite that pretty much all the other features of the RTF file format have been implemented and all known bugs have been ironed out (pun not intended). If for any reason a bug or crash occurs please report it in the "Issues" section of this GitHub repo.

# System requirements
OS/RX IronSlug, like all other OS/RX software, has tiny system requirements.
- Operating System: Mac OS X (10.1 or newer), Windows (XP or newer) and Linux (any that supports somewhat modern Java)
- Java Version: Java/OpenJDK 1.3 or newer
- Memory: 50MB to 130MB of free memory (depending on the Java version and file content)
